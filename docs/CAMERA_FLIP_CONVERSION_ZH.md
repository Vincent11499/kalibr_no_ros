# 相机上下左右同时翻转的内参转换

本规则依据用户于 2026 年 11 月 17 日核对手册后的确认，适用于本项目当前
IMX678 模组、3840×2160 输出及对应读出配置，在水平和垂直翻转状态之间转换标定参数。
后续转换以本规则为准。

## 主点和焦距

当源参数对应的图像状态与目标状态相差一次水平和垂直同时翻转时：

```text
fx' = fx
fy' = fy
cx' = 3856 - cx
cy' = 2184 - cy
```

`fx/fy/cx/cy` 单位均为 px。3856 和 2184 是手册确认的转换常数，直接使用，
不再减 1，也不从输出图像宽高重新计算。它们不表示将 `resolution` 改成 3856×2184；
当前输出分辨率仍是 3840×2160。

常见无 skew 的内参矩阵转换为：

```python
K_new = np.array([
    [fx, 0.0, 3856.0 - cx],
    [0.0, fy, 2184.0 - cy],
    [0.0, 0.0, 1.0],
])
```

若模型包含 skew，水平和垂直同时翻转时 `K[0,1]` 保持不变；完整
`pinhole-opencv-fisheye` 的 `alpha` 也保持不变。

每目根据自身源、目标图像配置判断是否转换：相同状态直接使用原参数，状态相差一次
双翻转则转换一次，不能按左目或右目固定套用。源参数已经适配目标状态时不再转换。
该转换是自逆的，反向转换仍使用同一公式。

## 按畸变模型转换

这里使用焦距保持正值、相机归一化坐标轴同时反向的约定：
`x'=-x, y'=-y, z'=z`。畸变参数按模型中的实际含义处理，不能仅凭系数个数判断。

| 模型 | 原畸变参数顺序 | 双翻转后的畸变参数 |
|---|---|---|
| `pinhole-equi`，以及本项目 EEPROM 的径向 KB4 | `[k1,k2,k3,k4]` | 全部不变 |
| `pinhole-opencv-fisheye` | `[k1,k2,k3,k4]` | 全部不变 |
| `pinhole-radtan` | `[k1,k2,p1,p2]` | `[k1,k2,-p1,-p2]` |
| `pinhole-radtan5` | `[k1,k2,p1,p2,k3]` | `[k1,k2,-p1,-p2,k3]` |
| `pinhole-radtan8` | `[k1,k2,p1,p2,k3,k4,k5,k6]` | `[k1,k2,-p1,-p2,k3,k4,k5,k6]` |
| `pinhole-fov` | `[w]` | `w` 不变 |
| `omni-radtan` | `[k1,k2,p1,p2]` | `[k1,k2,-p1,-p2]`；投影参数 `xi` 不变 |
| `omni-none` | `[]` | 仍为空；投影参数 `xi` 不变 |
| `eucm-none` | `[]` | 仍为空；投影参数 `alpha/beta` 不变 |
| `ds-none` | `[]` | 仍为空；投影参数 `xi/alpha` 不变 |

径向项只依赖半径或入射角，双翻转后不变；radtan 的切向参数 `p1/p2` 均取反。
例如四系数 KB4 的 D 不变，而同样是四系数的 radtan 不能整体照抄。
模型的完整参数顺序见[相机模型说明](CAMERA_MODELS_ZH.md)。未列出的模型需要先依据
其投影公式确认，不默认令 D 不变。

## 使用边界和历史规则替代

- 本规则针对当前硬件配置的水平、垂直同时翻转，不作为其他传感器、任意读出窗口或
  仅单方向镜像的通用公式。
- 后续不再使用此前按输出宽高计算主点的方案，也不再叠加实验拟合的主点偏移；
  不从历史报告中挑选其他翻转常数。
- `pos/neg` 是采集状态标签，必须对应到每目的实际配置以及 EEPROM 参数的原始方向。
  不能仅因模组物理安装倒置，就对已经适配图像方向的参数再转换一次。
- 本文是参数转换约定，不增加 CLI 自动转换开关，也不自动修改已有标定 YAML。
  使用转换结果验证时保持该方案 K/D 固定，只逐帧估计标定板位姿。
- 历史实验报告、残差与指标保留其原始计算口径，不得改成使用本规则得到的结果。
  新规则生效不表示已经使用新常数重新完成了真实数据验证。

滚动快门图像的纵坐标参考同时发生变化时，行时间及第 0 行时间戳还需按
[RS 图像预处理说明](ROLLING_SHUTTER_CAMERA_CALIBRATION_ZH.md#52-图像预处理会改变行时间参数的含义)
保持一致；这不改变上面的 K/D 转换规则。
