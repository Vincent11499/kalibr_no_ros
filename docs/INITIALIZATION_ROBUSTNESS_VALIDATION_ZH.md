# 显式初值收敛域验证报告

验证日期：2026-08-26。

本报告验证三类初值：高质量历史结果的 `10%` 内确定性随机扰动、明显错误的相机
内参，以及明显错误的相机/Camera–IMU 外参。它回答的是“当前 EuRoC 数据和当前阶段机
能否从这些初值恢复”，不是所有设备和运动条件下的全局收敛证明。

## 1. 固定条件

- 数据：EuRoC 双目相机 bag 和双目–IMU bag；
- 相机模型：`pinhole-radtan5`，`shuffle: false`；
- IMU 模型：`scale-misalignment`；
- 并行预算：`detector_processes=4`、`optimizer_threads=4`；
- 数值基线：冻结的 `camera_project_4` 和 `imu_project_4`；
- 随机种子：`20260826`；
- 旋转扰动：轴角左乘，始终保持有效旋转矩阵；
- 平移扰动：相对原平移向量范数定义；
- 耗时和内存：`/usr/bin/time -v` 的 wall 和 maximum RSS；不是进程树 PSS。

`10%` 历史初值夹具位于
[`../config/euroc_init/`](../config/euroc_init/README_ZH.md)，差内参和大外参夹具位于
[`../config/euroc_bad_init/`](../config/euroc_bad_init/README_ZH.md)。两类目录都提供
已经内嵌 `strategy: refine` 的可运行 task。

## 2. 扰动定义

### 2.1 相机历史值随机扰动

- 内参最大相对扰动：`8.603%`；
- 畸变最大相对扰动：`8.585%`；
- 双目旋转扰动：`2.786 deg`；
- 双目平移扰动：`3.845 mm`。

### 2.2 明显错误的相机内参

- 两个相机的 $f_x/f_y$ 分别缩放为 `0.65/1.35` 和 `1.35/0.65`；
- 主点分别移动图像宽、高的 `15%`；
- 五个 `radtan5` 畸变参数全部置零；
- 双目外参保持冻结值。

### 2.3 明显错误的双目外参

- 旋转误差：`25 deg`；
- 平移误差：冻结 baseline 长度的 `50%`；
- 相机内参与畸变保持冻结值。

### 2.4 Camera–IMU 历史值随机扰动

- Camera–IMU 旋转扰动：`3.558 deg`；
- Camera–IMU 平移扰动：`5.449 mm`；
- 重力方向扰动：`2.534 deg`；
- 两相机时间偏移最大相对扰动：`2.758%`；
- IMU scale/misalignment 扰动的是相对单位阵的物理误差量，幅度不超过 `10%`；
- gyro bias 以原生 preliminary LM 的结果为历史值，再施加不超过 `10%` 的扰动。

### 2.5 明显错误的 Camera–IMU 外参

- 旋转误差：`25 deg`；
- 平移误差：冻结 Camera–IMU 平移长度的 `50%`，即约 `34.04 mm`；
- 时间偏移和 IMU 内参保持冻结值；
- gyro bias 使用原生 preliminary LM 的历史结果。

关键观察：

1. `refine` 在三个压力场景中都恢复了冻结解；最终 `results.txt` 字节一致；
2. `direct` 能处理本次 `10%` 历史值扰动，但选帧不同，只得到残差等价的邻近解；
3. 差内参 `direct` 在姿态初始化阶段达到最大迭代，只保留
   `initialization_report.yaml`，没有输出伪结果；
4. 大外参 `direct` 更危险：它输出 hard full-rank 结果，却通过改变内参来拟合错误外参；
5. 因而 hard rank 只说明局部线性系统没有严格零空间，不能证明已进入正确物理解；
6. `direct` 也不保证更快：本次历史扰动和大外参 direct 均比对应 refine 更慢。

相机历史扰动 direct 的 operational rank 为 24/24，而冻结路径为 23/24。这是不同选帧
集合改变缩放后局部谱造成的，不表示它比冻结解更准确。

更快。因此即使该数据上 direct 成功，也不应把它作为大外参的默认策略。

## 5. 工程结论

推荐策略如下：

| 初值可信度 | 相机标定 | Camera–IMU 标定 |
|---|---|---|
| 同一硬件、近期高质量历史结果，误差预计在 `10%` 内 | 可用 `direct`，优先 `refine` 做首次验证 | 两者均可；`refine` 风险更低 |
| 内参明显不可信 | 必须 `refine` | 先单独重标相机；Camera–IMU 不会优化固定 camchain 内参 |
| 相机间外参可能有十几度以上误差 | 必须 `refine` | 不适用 |
| Camera–IMU 外参可能有十几度以上误差 | 不适用 | 使用 `refine` |
| 数据弱激励或来源未知 | 使用 `refine` | 使用 `refine` |

本轮暴露出一个需要后续增强的安全点：当前成功门控主要检查 hard rank，不能自动拒绝
“满秩但残差很大”的错误局部解。后续应增加：

1. 最终重投影/IMU residual RMS 的可配置门限；
2. seed 到最终物理参数的变化量报告；
3. 内参合理范围、baseline 长度变化和 operational deficiency 告警；
4. 可选 `auto` 策略：超出 direct 信任域时强制走 `refine`，不静默接受错误解。

## 6. 适用边界

本次随机验证只有固定种子 `20260826` 的一组代表性样本。它证明这组扰动可以收敛，
但不能据此声称“任意 `10%` 扰动都必然收敛”。若要给出统计成功率，还需对多个随机
种子、不同运动激励、不同数据长度和不同相机模型建立 Monte Carlo 矩阵。
